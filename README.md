# Instalujemy CS 1.6 w PortingKit

1. W PortingKit po lewej stronie wybierz:
   **Games → All Games → Custom port**, nazwij go dowolnie.

   ![1](1.png)

2. Ustawienia:

   * **Engine:** `WS12WineSikarugir10.0_3`
   * **Operating System:** `Windows 7`

   ![2](2.png)

3. W trakcie instalacji instalator poprosi o wskazanie instalatora CS.

4. Pojawi się komunikat o dostępie Wineskin do urządzeń w sieci — kliknij **Pozwól**.

   ![3](3.png)

5. Po kilku minutach powinno pokazać się okno instalatora CS.
   Jeśli się nie wyświetli, sprawdź pasek aplikacji – czasem otwiera się w tle.

   ![4](4.png)

6. Uruchom grę, wyjdź z niej i poczekaj, aż instalator zakończy pracę.

   ![6](6.png)

7. Pojawi się okno **Select main executable** — wybierz:
   **Counter strike 1.6.exe**

   ![7](7.png)

# Instalujemy Steam

1. W PortingKit przejdź do:
   **Games → All Games → steam**

   ![5](5.png)

2. Wybierz wersję:
   **Steambuild 32/64bit Direct3D**
3. Po instalacji uruchomi sie Steam
